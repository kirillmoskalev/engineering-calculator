# 🧮 Инженерный калькулятор

## 📌 О проекте
Данный проект представляет собой инженерный калькулятор, способный вычислять сложные арифметические выражения, введенные пользователем в виде строки. Программа поддерживает числа в экспоненциальной форме (например, `1.2e-10`), базовые арифметические операции, скобки, а также математические функции: синус, косинус, тангенс, логарифм и экспоненту.

## 🎯 Цели проекта
1. Разработка программного обеспечения с соблюдением принципов программной инженерии (модульность, читаемость кода, разделение ответственности).
2. Реализация алгоритма синтаксического разбора (парсинга) арифметических выражений (например, с использованием алгоритма сортировочной станции или рекурсивного спуска).
3. Освоение системы контроля версий Git и платформы GitHub для ведения документации, истории изменений и совместной разработки.
